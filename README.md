# Threat Model and Secure Configuration

## Project Overview
This project focuses on identifying security threats in a small Student Portal web application and preparing a security improvement plan.

## Project Objectives
- Identify important application assets.
- Understand users and data flow.
- Identify possible security threats using STRIDE.
- Rank risks based on likelihood and impact.
- Recommend security controls.

## Application Description
The Student Portal is a sample web application where students can log in and access their personal information.

## Main Components
1. Student/User
2. Web Browser
3. Web Application
4. Backend Server/API
5. Student Database

## Security Scope
This project is a beginner-level threat modelling exercise using a fictional Student Portal.

## Deliverables
- Threat Model Diagram
- STRIDE Threat Analysis
- Risk Register
- Security Hardening Checklist
